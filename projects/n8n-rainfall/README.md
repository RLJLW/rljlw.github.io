# n8n Data Demo

This is a simple project to show n8n features.

## n8n HTML Rainfall Data

This data can be actively created by a n8n form, or modified internally.

[Current Rainfall Data](https://brown-lemur-226119.hostingersite.com/webhook/044fb02d-9416-4297-9905-b862a1ed93e1)

## n8n Submit a Rainfall Reading Form

Add data to a data table via a simple n8n web form.

This form requires the correct access key to add the data (otherwise the input will be ignored).

[Add Rainfall Reading Form](https://brown-lemur-226119.hostingersite.com/form/7c1e26d9-4844-455e-8f7b-be835048c12d)

Ask a Chat interface to return rainfall data.
Use the word "show" in your response.

[Chat Example showing Rainfall Data](https://brown-lemur-226119.hostingersite.com/webhook/2d6d3ef0-8629-4138-a58b-0639d2115f69/chat)
